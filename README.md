# KONAS PERSADIA 2026 Portal

Aplikasi portal resmi untuk kegiatan **KONAS PERSADIA 14 SURAKARTA TAHUN 2026**.
Dibangun menggunakan React 19, Vite, TypeScript, Tailwind CSS, dan Supabase sebagai backend database.

## 🚀 Fitur Utama
- **Landing Page Interaktif**: Berisi informasi acara, jadwal, pembicara, tarif registrasi, dll.
- **Sistem Registrasi**: Formulir pendaftaran multi-langkah dengan penyesuaian tarif dinamis dan generator kode unik pembayaran.
- **Dashboard Admin**: Panel admin untuk melihat dan memverifikasi status pendaftar, dilengkapi dengan grafik analitik (menggunakan *recharts*).
- **Scanner QR Code**: Halaman terpisah khusus untuk *on-site check-in* menggunakan kamera perangkat untuk membaca QR code registrasi.

---

## 🛠️ Persyaratan Sistem (Prerequisites)
Pastikan sistem Anda telah menginstal:
- **Node.js** (versi 18 atau lebih baru)
- **npm** (biasanya sudah termasuk dalam instalasi Node.js)
- **Akun Supabase** (untuk backend database)

---

## ⚙️ Langkah-langkah Instalasi

### 1. Kloning dan Install Dependencies
Clone repositori ini, lalu masuk ke foldernya dan jalankan perintah install:
```bash
npm install
```

### 2. Setup Database (Supabase)
Aplikasi ini membutuhkan database Supabase dengan tabel `pendaftar`.
1. Buat project baru di [Supabase](https://supabase.com/).
2. Masuk ke **SQL Editor** di dashboard Supabase Anda.
3. Jalankan *query* berikut untuk membuat tabel `pendaftar`:

```sql
CREATE TABLE public.pendaftar (
  id BIGINT GENERATED BY DEFAULT AS IDENTITY PRIMARY KEY,
  timestamp TIMESTAMPTZ DEFAULT NOW(),
  no_registrasi TEXT NOT NULL,
  status_pembayaran TEXT,
  nama_lengkap TEXT NOT NULL,
  email TEXT,
  whatsapp TEXT,
  kategori_peserta TEXT,
  pilihan_kegiatan TEXT,
  total_tagihan BIGINT,
  institusi TEXT,
  nim TEXT,
  no_ktp TEXT,
  cabang_persadia TEXT,
  slot_waktu_cek_gula TEXT,
  registrasi_onsite TEXT,
  makan_siang_hari_1 TEXT,
  makan_siang_hari_2 TEXT,
  seminar_kit TEXT,
  cek_gula_darah TEXT
);
```

4. Pastikan Anda mengatur **Row Level Security (RLS)** pada tabel ini, atau matikan *RLS* untuk tahap pengembangan awal (meskipun tidak disarankan untuk produksi).

### 3. Konfigurasi Environment Variables
1. Duplikat file `.env.example` dan ubah namanya menjadi `.env.local` (atau `.env`).
2. Masuk ke dashboard Supabase Anda -> **Project Settings** -> **API**.
3. Isi nilai-nilai konfigurasi pada file `.env.local`:
```env
VITE_SUPABASE_URL=https://<project-id>.supabase.co
VITE_SUPABASE_ANON_KEY=<kunci-anon-anda>
```

### 4. Jalankan Aplikasi
Jalankan development server:
```bash
npm run dev
```
Aplikasi utama akan berjalan di `http://localhost:3000` (atau port lain yang tertera di terminal).

Untuk mem-build aplikasi agar siap di-deploy, jalankan:
